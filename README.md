# lab5-6-variant77
Доброго дня. моя робота з лабораторної роботи. Варіант - 77, Гламазда Є.М. К-27
У ході роботи розроблено застосунок «Електронна таблиця» для обчислення логічних виразів за варіантом 77. Реалізовано двоетапну обробку виразів: синтаксичну перевірку з вказівкою позиції помилки та власне обчислення з контролем типів. Для розбору використано генератор парсерів ANTLR4 із граматикою, що враховує пріоритет операцій. Логіку відокремлено від інтерфейсу, тому її можна повторно використати в іншому застосунку, а інтерфейс .NET MAUI легко змінювати без впливу на обчислення. Програма підтримує посилання між клітинками, виявляє циклічні залежності, працює з числами довільної довжини, дає змогу змінювати розмір таблиці, зберігати та відкривати дані. 

Прикріпила вам файл з моїм проектом в RAR форматі, через те що github не дав завантажити більше 100 файлів нажаль.
